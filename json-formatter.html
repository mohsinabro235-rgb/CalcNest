JSON Formatter

Paste JSON to format it with clean indentation, shrink it into one line, or find out exactly why it is invalid.

How it works

The tool reads your text with the same JSON parser that browsers use. If it is valid, Format rewrites it with two-space indentation and Minify removes all extra spaces and line breaks. If it is not valid, you see the parser's error message so you can find the mistake. Your data never leaves your browser.

Frequently asked questions

What are the most common JSON errors?

Trailing commas, single quotes instead of double quotes, unquoted keys and missing brackets are the usual causes.

Is it safe to paste private data here?

The tool runs in your browser and nothing is uploaded. Even so, avoid pasting passwords or secret keys into any online tool.

What is the difference between format and minify?

Format adds indentation so humans can read it. Minify removes extra spaces so the file is as small as possible for sending over a network.
