QR Code Generator

Type a link or any text, then generate a QR code you can scan right away and download as a PNG image.

How it works

The tool encodes your text or link into a square pattern of dots using a standard QR code format that every phone camera can read. The code is drawn in your browser, so what you type is never uploaded. Use the download button to save the image as a PNG.

Frequently asked questions

Is the QR code free to use?

Yes. The codes are free, have no expiry date and can be used on posters, cards, menus or websites.

What can I put in a QR code?

Website links, plain text, phone numbers, email addresses or Wi-Fi details written as text. Links are the most common use.

Why won't my QR code scan?

Make sure the text is correct, print the code at a decent size and keep a quiet white border around it. Very long text makes a denser code that is harder to scan.
