Password Generator

Choose a length and character types to generate a strong random password that is created privately in your browser.

How it works

Each character is picked using your browser's secure random number generator (crypto.getRandomValues), which is designed for security use. The tool always includes at least one character from every type you select, then shuffles them. Nothing is sent to a server or saved.

Frequently asked questions

Is it safe to use a generated password?

Yes. The password is created in your browser and never leaves your device. Store it in a password manager rather than a note or a chat.

How long should my password be?

Aim for at least 14 to 16 characters with a mix of letters, numbers and symbols. Longer is stronger, especially for email and banking accounts.

Should I reuse the same password?

No. Use a different password for every account so a leak on one site cannot unlock the others.
